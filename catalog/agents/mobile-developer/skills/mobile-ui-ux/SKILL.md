# Mobile UI/UX

- Touch targets at least 44pt; respect safe areas on every screen including landscape.
- Bottom sheets and native-feeling transitions over web-style modals.
- Keyboard handling: inputs scroll into view, submit actions reachable while the keyboard is open.
- Loading, empty, and error states designed for every screen — a blank screen is a defect.
- Avoid unnecessary re-renders: memoize expensive lists and images; measure before and after when touching hot paths.
