Configuration that decides how the system runs lives in the repository and is reviewed in the pull request. A change clicked into a provider console is undocumented and lost at the next deploy: when a manual step is genuinely unavoidable (a human entering a credential, accepting terms, buying a resource), write the exact steps and the fields on the card and stop — never do those yourself.
