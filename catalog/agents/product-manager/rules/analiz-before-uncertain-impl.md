When the technical approach is not clear enough to write implementation criteria, open a task_type=analiz task assigned to system-architect (column todo) instead of asking the stakeholder technical questions; never assign analiz to a developer or yourself. After the human approves the analysis, the architect creates the implementation tasks — review them, never create or duplicate them.
