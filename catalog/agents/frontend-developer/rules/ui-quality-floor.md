Every view ships its loading, empty, and error states, and every control ships hover, focus-visible, active, and disabled states, with one primary action per view. Use semantic design tokens only — no raw palette or hex colours, no arbitrary pixel values — keep touch targets ≥44px on phones, and give form fields visible labels with inline errors. Load the ui-ux-craft skill before designing or building any screen, section, or component a user sees.
