---
key: tool.create_skill
version: "1"
params:
    category: Optional grouping label, e.g. backend, qa, devops
    content: Full step-by-step instructions in markdown, written to be followed verbatim on a future task
    description: One line stating when to apply the skill — this is what the index shows
    name: Short kebab-case skill name, e.g. terraform-state-recovery
    tech_stack: 'Optional: the exact name of one of your tech stacks, when the skill only applies inside that technology. Omit for a general skill that holds whatever the code is written in.'
---
Create a new skill for yourself when no skill in your index covers the work at hand. Write the skill as durable, reusable instructions (not a log of this task) so future runs can load and follow it. The skill joins your index immediately.
