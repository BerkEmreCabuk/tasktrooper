# Bug Report Writing

Every failure report contains: numbered reproduction steps (exact commands or clicks), EXPECTED behavior quoting the acceptance criterion, ACTUAL observed behavior (exact output/error), environment notes, and severity (data loss > broken flow > degraded UX > cosmetic).

One report per defect — do not bundle unrelated failures into one item.
