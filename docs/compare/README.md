# How TaskTrooper compares

One page per project, same shape each time: what it is, where the two differ on the things that matter for shipping, and when to pick which. Several of these are tools TaskTrooper runs underneath rather than rivals.

Generated from the site's `content/compare.ts` with `node scripts/export-compare.ts`; edit there, not here.

| Project | Category | One line |
|---|---|---|
| [Claude Code](claude-code.md) | Agent CLI | The terminal agent TaskTrooper runs underneath. |
| [Cursor Cloud Agents](cursor.md) | Hosted coding agents | Parallel agents in cloud VMs that open merge-ready PRs. |
| [Devin](devin.md) | Hosted AI engineer | A cloud AI engineer you assign tickets to from Slack, Linear or Jira. |
| [GitHub Copilot coding agent](github-copilot.md) | Hosted coding agent | Assign an issue to Copilot and get a PR from a GitHub Actions runner. |
| [OpenHands](openhands.md) | Open-source agent platform | A self-hosted control center for coding agents and automations. |
| [Xirp](xirp.md) | Agentic development environment | An agent grounded in your organisation's services, docs and architecture decisions. |
| [Beads](beads.md) | Agent issue tracker | A git-embedded, dependency-aware issue tracker and memory for coding agents. |
| [Beadhive and Gas City](beadhive.md) | Software factory | A CLI software factory on top of Beads, with role agents and human gates. |
| [Vibe Kanban](vibe-kanban.md) | Kanban for coding agents | A kanban board where each task gets a branch, a terminal and a dev server. |
| [Claude Squad](claude-squad.md) | Session manager | A terminal UI that runs many agent sessions in tmux and git worktrees. |
